# 领域与跨边界数据契约

## 职责

定义进程桥接、来源适配、持久化及卡片层共享的数据形状和纯校验规则。帖子与上下文、成功推理结果、API 已执行/备用重置、待执行计划、预测和日报快照保持不同类型，避免把不同证据误当成同一事实。

X ID 保留十进制字符串，不能经浮点数转换；API 重置 ID 是受长度和字符约束的不透明字符串，不能套用 X ID 的假设。可缺失的概率及统计使用可空值，真实零值不等于缺失。API 来源链接经过 HTTPS/域名校验，不能把任意上游 URL 作为可信按钮。

## 边界

这里不读配置、不访问网络或数据库、不决定发送资格。类型有效性也不代表来源信息真实或当前仍有效：预测过期判定依赖调用方的观测时刻，日报保留自己的日期、时区和采集时间。业务解释见 `tibo-architecture`。

**未确认的长期约束（由现有导入关系推断）：**共享模型保持仅依赖标准库的底层包，不能反向依赖适配器。
