# 额度重置概率推理适配

## 职责

将帖子及有限的此前同作者证据转换为 TypeSafe System One 的 Noul 判断，问题限定为该动态是否预告、承诺或确认本次 Codex 使用/速率额度重置。文本是证据而非指令；不能把附近出现 reset、他人的请求或常规恢复当成目标作者的重置承诺。

独立过滤未来、重复和越窗历史并限制文本预算。概率来自经验证的真实 Noul 值；无效、缺失或非有限数不能当成零。有限重试共享一个整体截止时间，只重试符合条件的临时故障，不能缩短服务端要求的等待。

## 边界

不抓取新帖子、不读取业务库、不发送卡片，也不处理 API 重置/计划/预测/日报。缓存、跨目标合并和 debug 批次隔离属于 `tibo-architecture` 的发送编排契约，客户端本身不维护成功缓存。

只向固定推理端点发送所需证据，以 API Key 鉴权；不继承系统代理或跟随重定向，错误不携带原始响应。失败由调用方降级展示“暂不可用”，不生成替代分数。

**未确认的长期约束（由现有导入关系推断）：**保持可替换的推理适配器，仅依赖配置类型与领域模型。
